```java
@Service
public class InventoryService {

    @Transactional
    public void deductInventory(Long inventoryId, Integer quantity) {
        Inventory inventory = inventoryRepository.findById(inventoryId)
            .orElseThrow(() -> new RuntimeException("库存不存在"));

        // 扣减库存
        inventory.setQuantity(inventory.getQuantity() - quantity);

        // 自动变换状态
        if (inventory.getQuantity() == 0) {
            inventory.setStatus(InventoryStatus.OUT_OF_STOCK);
            sendAlert("库存告急：" + inventory.getProduct().getName());
        } else if (inventory.getQuantity() < inventory.getMaxQuantity() * 0.3) {
            inventory.setStatus(InventoryStatus.LOW_STOCK);
            sendWarning("库存偏低：" + inventory.getProduct().getName());
        } else {
            inventory.setStatus(InventoryStatus.NORMAL);
        }

        inventoryRepository.save(inventory);
    }
}
```

### ❹ AI创新点（本地部署）

**最终形态 - 3大AI功能完整实现**:

#### A. 智能推荐算法
**算法**: 用户协同过滤（User-Based Collaborative Filtering）

**实现方式**:
- 语言：Java
- 部署：Spring Boot应用内
- 数据：MySQL历史订单数据
- 更新：每日凌晨2点定时任务

**算法流程**:
```java
1. 构建用户-商品购买矩阵（稀疏矩阵）
2. 计算用户相似度（余弦相似度）
   similarity(A,B) = dot(A,B) / (||A|| * ||B||)
3. 找到最相似的K个用户（K=10）
4. 推荐这些用户购买过但当前用户未购买的商品
5. 按预测评分排序，返回Top 5
```

**性能指标**:
- 推荐准确率：60-70%
- 响应时间：<100ms
- 覆盖率：>80%（能为80%的用户提供推荐）

#### B. 异常检测算法
**算法**: Z-Score统计异常检测

**实现方式**:
- 语言：Java
- 部署：Spring Boot应用内
- 计算频率：每小时一次

**算法流程**:
```java
// 计算Z分数
double avgRevenue = calculateAverage(last7DaysRevenue);
double stdDeviation = calculateStdDeviation(last7DaysRevenue);
double zScore = (todayRevenue - avgRevenue) / stdDeviation;

// 判断异常
if (Math.abs(zScore) > 2) {  // 超过2个标准差
    if (zScore > 0) {
        alert("销售额异常增长：" + (zScore * 100) + "%");
    } else {
        alert("销售额异常下降：" + (zScore * 100) + "%");
    }
}
```

**检测维度**:
- 销售额异常（突增/突降）
- 商品销量异常（某商品突然热销）
- 设备故障异常（出货失败率突增）

**性能指标**:
- 检测准确率：75-80%
- 响应时间：<200ms
- 误报率：<15%

#### C. 销售预测算法
**算法**: 移动平均法 + 指数平滑法

**实现方式**:
- 语言：Java
- 部署：Spring Boot应用内
- 训练数据：最近30天销售数据

**算法流程**:
```java
// 简单移动平均（7天）
double MA7 = sum(last7DaysRevenue) / 7;

// 指数平滑（α=0.3）
double alpha = 0.3;
double forecast = alpha * actualRevenue + (1 - alpha) * lastForecast;

// 最终预测（加权平均）
double prediction = (MA7 + forecast) / 2;
```

**预测范围**:
- 未来1天销售额预测
- 未来7天销售趋势
- 未来30天库存需求

**性能指标**:
- 预测准确率（MAPE）：15-20%误差
- 响应时间：<300ms
- 适用范围：1-30天

```java
@PostMapping("/upload")
public ResponseEntity<String> uploadImage(@RequestParam("file") MultipartFile file) {
    // 验证文件类型
    String contentType = file.getContentType();
    if (!Arrays.asList("image/jpeg", "image/png", "image/gif").contains(contentType)) {
        throw new RuntimeException("不支持的文件类型");
    }

    // 验证文件大小
    if (file.getSize() > 5 * 1024 * 1024) {
        throw new RuntimeException("文件大小不能超过5MB");
    }

    // 保存到MinIO或本地
    String filename = UUID.randomUUID() + "_" + file.getOriginalFilename();
    String url = minioService.upload(file, filename);

    return ResponseEntity.ok(url);
}
```

```java
@Scheduled(fixedRate = 30000)  // 每30秒发送一次心跳

    heartbeat.setDeviceId(deviceId);
    heartbeat.setStatus("ONLINE");
    heartbeat.setCpuUsage(getCpuUsage());
    heartbeat.setMemoryUsage(getMemoryUsage());
    heartbeat.setTemperature(getTemperature());
    heartbeat.setTimestamp(System.currentTimeMillis());

// 服务端
@MessageMapping("/heartbeat")
public void handleHeartbeat(DeviceHeartbeat heartbeat) {
    Device device = deviceRepository.findById(heartbeat.getDeviceId())
        .orElseThrow();

    device.setStatus(DeviceStatus.ONLINE);
    device.setLastHeartbeat(new Date());
    device.setCpuUsage(heartbeat.getCpuUsage());
    device.setMemoryUsage(heartbeat.getMemoryUsage());
    device.setTemperature(heartbeat.getTemperature());

    deviceRepository.save(device);
}

// 离线检测
@Scheduled(fixedRate = 60000)  // 每分钟检查一次
public void checkOfflineDevices() {
    Date threshold = new Date(System.currentTimeMillis() - 2 * 60 * 1000);  // 2分钟
    List<Device> offlineDevices = deviceRepository
        .findByLastHeartbeatBefore(threshold);

    offlineDevices.forEach(device -> {
        device.setStatus(DeviceStatus.OFFLINE);
        deviceRepository.save(device);
        sendAlert("设备离线：" + device.getName());
    });
}
```

**实现方式**:
```java
// 服务端
@PostMapping("/devices/{deviceId}/products/{productId}/price")
public ResponseEntity<?> updatePrice(
    @PathVariable Long deviceId,
    @PathVariable Long productId,
    @RequestBody PriceUpdateRequest request
) {
    // 发送MQTT指令
    MqttMessage message = new MqttMessage();
    message.setTopic("device/" + deviceId + "/config/price");
    message.setPayload(JsonUtils.toJson(request));

    mqttClient.publish(message);

    // 记录操作日志
    configLogService.log(deviceId, "价格调整", request);

    return ResponseEntity.ok("指令已发送");
}

// 设备端（模拟）
@Subscribe(topic = "device/+/config/price")
public void handlePriceUpdate(MqttMessage message) {
    PriceUpdateRequest request = JsonUtils.fromJson(message.getPayload());

    // 更新本地价格
    localDb.updatePrice(request.getProductId(), request.getNewPrice());

    // 发送确认消息
    mqttClient.publish("device/" + deviceId + "/config/ack", "价格已更新");
}
```
